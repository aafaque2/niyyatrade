# Vision

Build the most transparent and educational virtual investing platform.

The platform should help users:

- Learn investing
- Simulate investing
- Understand investing decisions
- Build portfolios
- Evaluate investment frameworks
- Improve investing knowledge

The platform should not simply allow users to place virtual trades.

The platform should help users understand why decisions are made.

Education, transparency, and explainability are core principles.

---

- Portfolio Simulation
- Financial Analysis
- Educational Guidance
- Investment Frameworks

# Product Positioning

The platform is NOT:

- A broker
- A trading terminal
- A stock screener
- A religious platform
- A clone of existing investing products

The platform IS:

A modern investing operating system that allows users to experiment with different investing frameworks while learning how investing decisions are made.

---

# Core Differentiator

The Compliance Framework Engine.

Most investing simulators focus on:

- Virtual orders
- Charts
- Portfolio tracking

This platform focuses on:

- Why decisions are allowed
- Why decisions are blocked
- How frameworks affect investing behavior

The Compliance Framework Engine is the heart of the product.

Every investing action passes through framework evaluation.

# Compliance Framework Principles

Frameworks must be:

- Pluggable
- Extensible
- Explainable
- Auditable
- Configurable

Frameworks should never be hardcoded.

Frameworks should operate independently from the trading engine.

---

# Halal Investing Framework

Halal Investing Framework is the flagship framework.

It demonstrates the flexibility of the platform.

The platform itself should not be branded solely around halal investing.

Halal investing should be presented as one supported framework.

---

# Halal Framework Rules

Initial rules:

Debt To Equity <= 0.33

Trade Receivables <= 45% Market Capitalization

Interest Income <= 5% Market Capitalization

Other Income <= 5% Market Capitalization

Industry Exclusions

Examples:

- Conventional Banking
- Alcohol
- Gambling
- Tobacco
- Adult Entertainment

Rules must be configurable.
